LLP – gemeinsamer Ordner
========================

Fuer Kolleginnen und Kollegen zuerst:
  ANLEITUNG.txt  in diesem Ordner
  oder Pruefen.bat (Status ohne Schluessel)

Dieser Ordner gehört auf den Server nach:

  K:\LLP Wirtschaftsprüfung\AI Tools\_Gemeinsam

Nicht ins Git: .env (Schlüssel). Nur .env.example.

llp_ai
------
Einziger KI-Zugang für alle LLP-Tools, die ein Modell brauchen.
Anbieter ist fest Microsoft Foundry. Kein stiller Wechsel
auf Ollama, OpenAI oder Anthropic.

1. Bestehende Datei llp_ai\.env auf dem Server behalten
   (derselbe Zugang, der beim Anhangsprüfer schon ging).
2. Nicht neu anlegen, wenn die Datei schon da ist.
3. Starten.bat oder Desktop-Verknuepfung. Bleibt ein alter Weg,
   erscheint eine Zeile („Bitte Pruefen.bat“).
4. Status ohne Schlüssel: Pruefen.bat in diesem Ordner
   doppelklicken (Foundry, Nachbar-Tools, Restwege wie
   Mistral, CI-Rezepte, Anhang-Ollama, Fremd-KI;
   keine Schlüssel).
5. Anderes Tool anbinden: `from llp_ai.company_ai import ask_ai, is_ai_ready`.
   Kein eigener OpenAI-/Ollama-Client.
   Ist Foundry aus: Anhangspruefer Heuristik,
   Text verbessern sagt Bescheid und aendert den Text nicht.

Ist Foundry aus oder nicht erreichbar:
  Anhangspruefer arbeitet ohne Modell (Heuristik).
  Text verbessern aendert den Text nicht.

llp_start
---------
Gemeinsames Startmenue (Start.bat). Oeffnet die Tools
im Nachbarordner, kopiert sie nicht.

text_verbessern_foundry
-----------------------
Starten.bat und das Startmenue stellen Text verbessern
bei jedem Start um. Bleibt ein alter Weg, Pruefen.bat.
Oder einmal Anwenden.bat in diesem Ordner.

Pseudokrat bleibt lokal und nutzt llp_ai nicht.
