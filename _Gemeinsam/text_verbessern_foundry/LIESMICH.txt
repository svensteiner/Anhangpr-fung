Text verbessern auf Foundry umstellen
=====================================

Einmal auf dem Server ausführen, wenn „Text verbessern“
noch „Gründlich mit Mistral“ zeigt.

1. Doppelklick auf  Anwenden.bat  in diesem Ordner.
2. Das Programm findet den Nachbarordner rephraser
   oder paraphraser und stellt die gründliche Fassung
   auf Microsoft Foundry (llp_ai) um.
3. Schnell bleibt lokal (Regeln). Es gibt keinen stillen
   Wechsel auf Ollama oder ein anderes Modell.
4. Danach Text verbessern wie gewohnt starten
   (TEXT VERBESSERN.cmd oder llp_start\Start.bat, Punkt 2).

Nicht nötig, wenn das Tool bereits „Gründlich mit Foundry“
zeigt. Ein zweiter Lauf ändert nichts.

Schlüssel bleiben nur in llp_ai\.env.
Keine EXE, nichts auf den PC kopieren.
